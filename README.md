# Spaceship Titanic - Machine Learning Classification

A Machine Learning classification project based on Kaggle's
Spaceship Titanic competition.

## Objective

Predict whether a passenger was transported to an alternate
dimension based on passenger and travel-related information.



1. Data Loading
2. Data Understanding
3. Missing Value Analysis
4. Data Cleaning
5. Exploratory Data Analysis
6. Feature Engineering
7. Categorical Encoding
8. Model Training
9. Model Evaluation
10. Kaggle Submission

## Kaggle Result

- Score: 0.80570
- Accuracy: ~80.57%
- Leaderboard Position: 347
